# ReoliOS — Guia de Instalação

## Pré-requisitos
- Claude Code (`npm install -g @anthropic-ai/claude-code`)
- Node.js 18+
- Git

## Instalação Global via CLI (Recomendado)

```bash
npm install -g F:\Projetos\.Reoli-AI\ReoliOS
```

Agora você pode aplicar o ReoliOS em qualquer diretório de projeto executando:

```bash
reolios
```

## Instalação por Clonagem Manual
```bash
git clone https://github.com/PedroReoli/skill-ReoliOS.git meu-negocio
cd meu-negocio
code .
```

## Primeiros passos
1. `/instalar` — configura seu negócio em 5 minutos
2. `/abrir` — carrega o contexto antes de trabalhar
3. Escolha uma skill: `/carrossel`, `/copy-vendas`, `/seo`

## Opcionais
- Playwright: `npm install` (renderizar carrosséis)
- OpenAI API key (gerar fotos com IA)
- Meta Graph API tokens (postar automático)
