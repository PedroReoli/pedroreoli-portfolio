# Casos de Uso

## Quando usar o ReoliOS

### Criar conteudo visual

**Situacao:** Voce precisa criar 10 posts para Instagram estao semana.

**Solucao:**
1. `/publicar-tema` - Gere tema central
2. `/carrossel` - Crie carrosseis
3. `/aprovar-post` - Publique tudo

**Resultado:** 10 posts profissionais em 1 hora.

---

### Gerar proposta comercial

**Situacao:** Cliente potencial quer proposta ate sexta.

**Solucao:**
1. `/proposta` - Gere estrutura
2. `/copy-vendas` - Adicione copy persuasiva
3. `/email-profissional` - Envie por email

**Resultado:** Proposta profissional em 30 minutos.

---

### Analisar dados de vendas

**Situacao:** Precisa entender por que as vendas caíram este mes.

**Solucao:**
1. `/analisar-dados dados/vendas.csv` - Analise os dados
2. `/relatorio-ads` - Veja performance dos anuncios
3. `/analise-mercado` - Entenda o mercado

**Resultado:** Relatorio executivo com insights.

---

### Construir um sistema

**Situacao:** Cliente quer um sistema SaaS completo.

**Solucao:**
1. `/criar-api` - Crie o backend
2. `/modelar-db` - Defina o banco
3. `/frontend` - Crie a interface
4. `/security` - Implemente seguranca
5. `/testar` - Crie testes
6. `/deploy` - Faca deploy

**Resultado:** Sistema production-ready.

---

### Protegerse com LGPD

**Situacao:** Sua empresa precisa estar compliant com LGPD.

**Solucao:**
1. `/lgpd` - Mapeie dados
2. `/legal` - Crie politicas
3. `/security` - Implemente seguranca
4. `/audit` - Verifique tudo

**Resultado:** Empresa compliant e protegida.
