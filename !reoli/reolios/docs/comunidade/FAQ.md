# FAQ - Perguntas Frequentes

## O que e o ReoliOS?

ReoliOS e um sistema operacional de negocio que roda dentro do Claude Code. Ele transforma o Claude numa equipe completa: marketing, SEO, ads, conteudo, atendimento, operacao.

## Quanto custa?

R$ 450 (pagamento unico, vitalicio).

## Preciso saber programar?

Nao! As skills de marketing, operacao e comercial sao acessiveis a qualquer pessoa. As skills de desenvolvimento sao para quem quer construir.

## Quais skills estao inclusas?

40 skills cobrindo: nucleo, marketing, ads, operacao, dev, database, devops, pagamento, qualidade, comunicacao, performance, seo, legal, mercado, documentacao.

## Como funciona?

1. Clone ou baixe o repositorio
2. Abra no Claude Code
3. Digite `/instalar` para configurar
4. Use as skills!

## Posso criar minhas proprias skills?

Sim! Use `/mapear-rotinas` ou crie manualmente em `.claude/skills/`.

## Funciona em Windows, Mac e Linux?

Sim!

## Tem suporte?

Nao tem suporte individual, mas voce tem acesso ao grupo VIP.

## Como atualizo?

Basta fazer `git pull` ou baixar a nova versao.

## Posso sugerir novas skills?

Sim! Abra uma issue ou use `/mapear-rotinas` para criar sua propria.
