# Regra de TODO

## Objetivo

Impedir que o TODO se transforme em arquivo de governança difusa.

## Regras

- TODO deve conter apenas sprint atual, backlog técnico e concluído recentemente
- TODO não deve guardar regras permanentes
- TODO não deve concentrar arquitetura
- TODO não deve substituir documentação de produto
- TODO deve refletir andamento real

## Resultado esperado

O arquivo continua útil como painel de progresso e não como depósito de contexto.
