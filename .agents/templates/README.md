# Templates

## O que sao templates?

Templates sao modelos prontos que podem ser reutilizados para tarefas comuns.

## Tipos de Template

### Email Templates
- Boas-vindas
- Recuperacao de senha
- Confirmacao de compra
- Newsletter

### Proposta Templates
- Proposta comercial
- Contrato de servico
- Termo de referencia

### Carrossel Templates
- Educativo
- Promocional
- Testemunhal
- Comparativo

### Documentacao Templates
- README
- CHANGELOG
- CONTRIBUTING

## Como usar

1. Copie o template desejado
2. Personalize com seus dados
3. Use com a skill apropriada

## Contribuir

Se tem um template legal, adicione na pasta `templates/` e faca um commit.
