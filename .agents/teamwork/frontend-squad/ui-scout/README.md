# UI-Scout: Dossiê de Pesquisa & Referências Visuais — Redesign Pedro Reoli

Diretório de entrega das pesquisas de UI/UX, arquitetura visual e microinterações para a equipe do Frontend Squad.

## Arquivos Entregues:
1. [`01-rail-projetos-alternado.md`](./01-rail-projetos-alternado.md): 7 referências reais de layout em rail alternado (Basement, Locomotive, Studio Freight, Minimalissimo, CodePen, v0.dev, B-Reel) para a Seção 3.
2. [`02-video-wallpaper-backdrop.md`](./02-video-wallpaper-backdrop.md): 5 referências de video backdrop full-bleed contínuo com freeze frame e padrões de proteção de contraste (Apple, Stripe Press, Resn, CSS-Tricks, The Balvenie).
3. [`03-stack-grid-compacto.md`](./03-stack-grid-compacto.md): 4 referências de grid de tecnologias compactas de alta legibilidade (Linear, Raycast, Vercel, CodePen) para a Seção 4.
4. [`04-timeline-reveal-stagger.md`](./04-timeline-reveal-stagger.md): 3 padrões de microinteração com GSAP ScrollTrigger por card e remoção de poluição visual na Seção 6.

## Princípios Visuais Consolidados:
- **Identidade**: Editorial Premium, mármore branco esculpido, fundo preto obsidiana (`#08090b`), destaque amarelo (`#ffc900`), `Instrument Serif` + `Instrument Sans`.
- **Acessibilidade**: Fallback garantido por poster para conexões móveis, `saveData` e `prefers-reduced-motion`; conformidade WCAG AA/AAA com painéis translúcidos de scrim.
- **Engenharia**: Zero dependência de bibliotecas pesadas de terceiros; integração limpa com GSAP e React 19 já existentes no projeto.
