# Roteirização de YouTube e SEO

Estruture roteiro, título e descrição fiéis ao vídeo e à consulta do público. Meça retenção e descoberta após publicar; não presuma que tags garantem alcance.

---

## 🧭 Contexto do Negócio

Antes de iniciar, consulte ou solicite:
1. Qual o formato do vídeo? (Longo vs. Shorts/Reels).
2. Qual o tema central e a palavra-chave (keyword) alvo?
3. Qual é o tom do canal? (Educativo, Entretenimento, Técnico, Vlog).
4. Qual é a CTA (Chamada para Ação) principal? (Inscrição, link na bio, venda de produto).

---

## 📐 Estrutura de Roteiro de Alta Retenção (Vídeos Longos)

Divida o script em blocos focados em reter a atenção a cada minuto.

1. **The Hook (O Gancho - 0:00 a 0:30):** 
   - Deve prometer o valor do vídeo imediatamente, idealmente cortando direto para o problema sem enrolação. Sem vinhetas longas.
2. **Contexto Rápido / Prova (0:30 a 1:00):**
   - Por que o espectador deve ouvir você? Mostre um resultado ou estabeleça o problema.
3. **The Body (O Desenvolvimento - Blocos de 2-3 min):**
   - Divida em passos lógicos ou "segredos". Use quebras de padrão (b-roll, zoom, mudança de ângulo nas instruções visuais).
4. **O Clímax / Ponto Principal:**
   - Entregue o maior valor mais pro final para manter a retenção alta.
5. **A CTA (Chamada para Ação - Últimos 30s):**
   - Seja direto. Em vez de "curta, compartilhe, se inscreva, comente", peça **uma** ação clara. Ou sugira o próximo vídeo do canal.

---

## 🔍 Checklist de SEO e Metadados para YouTube

Para cada roteiro, forneça os metadados prontos para upload.

- [ ] **3 Opções de Títulos (Clickable, não Clickbait):** Incluir a palavra-chave exata perto do início. (Ex: *Como fazer X* vs *O Segredo de como fazer X em 2026*).
- [ ] **Ideia Visual para Thumbnail:** Sugestão do que deve aparecer na capa (texto grande de no máximo 4 palavras, elemento visual forte).
- [ ] **Descrição Otimizada:** Primeiro parágrafo deve conter a palavra-chave de forma natural. 
- [ ] **Timestamps (Capítulos):** `00:00 - O que você vai aprender`, `01:20 - O primeiro passo`, etc. (Ajuda no SEO do Google).
- [ ] **Tags:** use somente quando agregarem contexto, especialmente para variações de grafia. O YouTube informa que título, miniatura e descrição são muito mais relevantes; não fixe uma quantidade obrigatória de tags.

---

## ⚡ Estrutura para Shorts/Reels (Shorts do YouTube podem ter até 3 minutos, conforme elegibilidade)

1. **Gancho Visual e Falado (0-3s):** Frase de impacto (Ex: "Pare de fazer X se você quer Y").
2. **Valor Rápido (3-45s):** Informação densa e rápida, sem respiro.
3. **CTA Loop (45-60s):** Final que emenda naturalmente com o início do vídeo para gerar repetição.

## 📤 Formato de Saída (Output)

Sempre entregue:
1. **O Roteiro em Formato Tabela:** Coluna Esquerda (Áudio/Falas) | Coluna Direita (Visual/B-roll/Edição).
2. **Pacote de SEO:** Títulos, ideia de Thumb, Descrição com Timestamps e Tags.
